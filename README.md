# Workspace Vault

<p align="center"> <img src="/extension/icons/logo.png" alt="Workspace Vault logo" width="150" /> </p>

A browser extension that helps you save and restore browser tab groups as reusable workspaces.

## Features

- Save browser tab groups
- Restore saved tab groups anytime
- Save groups as bookmark folders
- Preserve tab group names and colors

## Supported Browsers

- Microsoft Edge
- Google Chrome
- Other Chromium-based browsers

## Installation (Development)

1. Clone this repository

2. Open your browser extensions page:

   ```text
   edge://extensions
   ```

   or

   ```text
   chrome://extensions
   ```

3. Enable **Developer Mode**
4. Select **Load unpacked**
5. Choose the `extensions` folder
